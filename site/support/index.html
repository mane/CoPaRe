Help, when you need it

A little support.

Find your way around CoPaRe, understand its privacy controls, or get in touch about something that needs a closer look.

Install or update

CoPaRe requires macOS 26.2 or later on an Apple silicon or Intel Mac. App Store updates arrive through Apple; the direct build has Check for Updates in its menu.

Using CoPaRe

How do I open Quick Copy?+

Press ⌥⌘V or choose Quick Copy from CoPaRe’s menu bar menu. Type to search, move with the arrow keys, and press Return to copy the selected item. Paste in your previous app with ⌘V. Escape closes the panel. If CoPaRe is locked, open its main window and unlock first.

Why isn’t a copy appearing in history?+

Check that monitoring is on and CoPaRe is unlocked. In Settings, review excluded apps, per-app rules, sensitive-content filtering, and the image or file capture options. Apps may mark their clipboard content as confidential or temporary, which CoPaRe respects. Captures made while monitoring is paused are not added later.

What is the difference between a pinned item and a snippet?+

Pinning keeps a captured item readily available during the current session; it is still cleared when you quit. A snippet is reusable text you explicitly save. Create one from scratch or save a captured text or URL as a snippet, then edit its title, content, and tags. Enable persistence to keep snippets in the encrypted local vault.

Where are my saved snippets after restarting?+

The regular saved-snippets vault is loaded on request. Use Load Saved Snippets to bring them into the current session; unlock first if protection is enabled. Pending snippet changes saved during locking are recovered after authenticated unlock. Clipboard captures from the previous session are not restored.

How do encrypted backups work?+

Backups include snippets loaded in the current session. Load any saved snippets you want to include, then create an encrypted backup in Settings using a password of at least 12 characters. Keep the password somewhere safe: CoPaRe does not store it and cannot reset it. To move snippets to another Mac, transfer the file and restore it with the same password. Plain JSON export is a separate option and contains readable text.

How do I copy text from an image?+

Select an image, reveal its content, and choose Copy Text. Recognition runs locally using Apple’s Vision framework. The result goes to the system clipboard; it is not automatically added to searchable history or saved as a snippet. Changing the selection, hiding the image, leaving the app, or locking cancels a pending result.

What does automatic locking do?+

Enable unlock protection, then choose your automatic-lock settings. CoPaRe can lock on leaving the app, on Mac or display sleep and user switching, or after a period without interaction in CoPaRe. Capture pauses while locked. The inactivity timer uses input within CoPaRe and does not monitor typing in other apps.

Does deleting history also clear the system clipboard?+

No. History and the macOS system clipboard are separate. Use timed clipboard clearing to expire a copy made by CoPaRe. It clears that copy only if the system clipboard has not changed since. A newer copy from any app is preserved.

Why does the App Store show a different version?+

Direct releases and App Store updates have separate publication steps. A new direct release may be available while Apple reviews the App Store update. Use your installed channel’s normal update mechanism; both builds support the same core clipboard and privacy features.

Privacy and security reports

The privacy policy explains what stays in memory, what can be saved, and what happens when you choose actions such as web search. For a security-sensitive report, follow the repository’s security policy and avoid posting secrets publicly.
