Common Checks

  • Open CoPaRe from the menu bar if the main window is hidden.
  • Use CoPaRe > Check for Updates in the direct-download build.
  • Review Settings if capture, images, files, or shortcut behavior is not what you expect.
  • Use Secure Wipe if you want to clear local history and snippet vault keys.
