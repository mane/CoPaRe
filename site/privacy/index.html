Privacy Policy

CoPaRe is designed as a local macOS clipboard utility. It does not collect personal data, require an account, use analytics, or sync clipboard contents to a cloud service.

App Store privacy summary: Data Not Collected.

Data Collection

CoPaRe does not collect, sell, or rent personal data, or automatically upload your clipboard contents. The app does not include advertising SDKs, analytics SDKs, third-party telemetry, account creation, subscriptions, or cloud sync.

Clipboard Contents

Clipboard processing happens locally on your Mac. Captured clipboard history is session-only and is cleared when CoPaRe quits. CoPaRe does not send clipboard text, URLs, file paths, images, or snippets to CoPaRe servers.

Quick Copy searches the titles, previews, tags, and source-app information already available in the app. Opening the panel does not decrypt item contents. Choosing a copy action writes the selected content to the macOS clipboard.

Saved Snippets

If you explicitly save snippets and enable persistence, CoPaRe stores those user-created snippets locally in an encrypted vault on your Mac. You can create, edit, duplicate, or save a captured text or URL entry as a snippet. Creating a snippet from history requires an explicit Save action; the original captured entry remains session-only. Encryption keys are protected with Apple platform security APIs, including Keychain where applicable.

When persistence and unlock protection are enabled, pending snippet changes and deletion markers are also saved in an encrypted local recovery file. This prevents automatic locking followed by quitting from discarding those changes. They are recovered after authenticated unlock and merged into the saved-snippets vault; the recovery file is removed after a successful save. Captured clipboard history is never included. Secure Wipe removes the recovery file and its protected key along with the saved-snippets vault.

During an unlocked session, CoPaRe retains the protected lock key and authenticated macOS authorization in memory so that vault operations can use that authorization. Locking discards the cached key and invalidates the authorization. The normal saved-snippets vault is loaded on request; pending changes from the recovery file are restored after authenticated unlock.

Snippet titles and tags are visible in the list while CoPaRe is unlocked. Revealed contents are cleared from the detail view when you leave the app. The snippet editor hides its fields while the app is inactive, retaining unsaved edits until you return; locking the app dismisses the editor.

Snippet Backups and Exports

You can create a password-protected encrypted backup of snippets loaded in the current session and restore it on another Mac. Encryption and decryption happen locally. CoPaRe does not save or transmit the backup password and cannot recover it. Captured clipboard history is not included in snippet backups.

Plain JSON import and export are also available. JSON exports contain readable snippet titles, bodies, and tags. CoPaRe writes backups and exports only to a location you choose; any file-provider synchronization depends on that location and your macOS settings. Exported files are separate from the local vault and are not removed by Secure Wipe.

Text Recognition in Images

If sensitive-image scanning is enabled, CoPaRe uses Apple's Vision framework locally to help detect sensitive text in captured images. Separately, you can reveal an image and choose Copy Text to recognize and copy its text to the macOS clipboard. Images and recognized text are not sent to an online recognition service.

Copy Text does not add recognized text to searchable history or save it as a snippet. Pending results are discarded if you change the selected image, leave the app, hide its revealed content, or lock CoPaRe.

Automatic Locking and Clipboard Clearing

When unlock protection is enabled, optional automatic locking can respond to leaving CoPaRe, Mac or display sleep, switching users, or a configured period without interaction in CoPaRe. The inactivity timer observes input within CoPaRe; it does not record typing in other apps. Capture is paused while the app is locked.

You can also set a delay after which CoPaRe clears a copy it placed on the system clipboard. It clears that copy only if the clipboard has not changed in the meantime. Removing an item from CoPaRe's history alone does not remove its copy from the system clipboard.

Actions You Choose

If you choose Search on Web for an item, CoPaRe opens a Google search for that item's text in your default browser. If you choose Open URL, the browser opens that address. These actions share the search text or requested address with the selected website and are subject to that service's privacy policy.

Diagnostics and Updates

The Mac App Store version receives updates through Apple. Apple may process App Store, purchase, crash, or diagnostic information according to your Apple settings and Apple's privacy policies.

The direct-download version may check a signed appcast hosted on GitHub when update checks are enabled. Those network requests are handled by GitHub and the operating system, not by a CoPaRe analytics service.

Privacy Choices

Because CoPaRe does not collect remote user data, there is no CoPaRe account or server-side profile to access, export, or delete. You can manage local data on your Mac by:

  • using Secure Delete for individual clipboard entries,
  • using Secure Wipe to clear history and saved snippets,
  • choosing automatic locking and timed system clipboard clearing in Settings,
  • managing or deleting exported snippet files at their chosen locations,
  • turning off snippet persistence in Settings,
  • deleting CoPaRe and its local app container data from macOS.

Support Requests

If you contact support through GitHub Issues or another channel, the information you choose to provide is handled by that service and may be visible according to the service's settings. Do not include passwords, private keys, tokens, or confidential clipboard contents in support requests.

Changes

This policy may be updated when CoPaRe's behavior changes. Material changes will be reflected on this page.
