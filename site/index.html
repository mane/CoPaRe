A few things to know

Clear from the start.

What happens when I quit CoPaRe?+

Captured clipboard history is cleared, including pinned captures. Snippets you explicitly save can remain in the encrypted local vault if persistence is enabled. Quitting does not itself clear the macOS system clipboard; timed clipboard clearing is a separate setting.

Does CoPaRe upload my clipboard?+

Clipboard processing and image text recognition happen locally. There are no accounts, analytics, or cloud sync. If you choose Search on Web or Open URL, your browser connects to that website. The direct build can check GitHub for updates. See the privacy policy for details.

How do I move snippets to another Mac?+

Load the snippets you want to move, then create an encrypted backup in Settings. Transfer that file yourself and restore it with the same password on your other Mac. CoPaRe cannot recover a forgotten backup password. Plain JSON export is also available and contains readable text.

Does Quick Copy paste automatically?+

Return copies the selected item and restores focus to your previous app. Paste normally with ⌘V. CoPaRe does not inject keystrokes and does not require Accessibility permission.

Which Macs are supported?+

CoPaRe requires macOS 26.2 or later and supports both Apple silicon and Intel Macs. Choose the Mac App Store version for updates through Apple, or the signed and notarized direct build for updates through CoPaRe.
