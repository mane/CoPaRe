# CoPaRe 1.3.8

CoPaRe 1.3.8 keeps the GitHub release focused on the signed manual installer and includes small privacy and data-fidelity fixes.

## Highlights

- Captured text and saved snippets now preserve leading and trailing whitespace.
- Secure wipe now removes both current and legacy Keychain-backed snippet keys.
- The GitHub project no longer carries the separate store-distribution target in the current tree.

## Upgrade notes

- No data migration is required.
- Existing saved snippets remain compatible.
