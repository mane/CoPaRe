# CoPaRe 1.3.7

CoPaRe 1.3.7 adds an explicit manual update check to the menu bar app so Sparkle updates are reachable without going through the app menu.

## Highlights

- Added `Check for Updates…` directly in the menu bar menu.
- Added the same manual update action in Settings under `Updates`.
- The update action now disables itself while a Sparkle session is already in progress.

## Upgrade notes

- This release is intended to make in-app update testing straightforward from 1.3.6 onward.
