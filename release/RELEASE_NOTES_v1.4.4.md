# CoPaRe 1.4.4

CoPaRe 1.4.4 strengthens clipboard privacy, vault reliability, and everyday behavior.

- Makes lock and unlock transitions atomic so history is never cleared before encrypted snippet persistence succeeds.
- Prevents deleted snippets from returning when saved snippets have not yet been loaded.
- Revalidates sensitive-image OCR and per-app capture rules before deferred captures are stored.
- Improves one-time-copy handling, URL and file detection, settings validation, onboarding, shortcuts, and QR privacy.
- Hardens App Store, security-check, versioning, and direct-release scripts.
