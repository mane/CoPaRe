# CoPaRe 1.5.1

CoPaRe 1.5.1 fixes the menu bar history becoming too wide when clipboard text is long.

- The menu keeps a fixed width of 400 points, with empty, short, or long content.
- Previews and source-app names stay on a single line. Text that does not fit ends with an ellipsis.
- Line breaks and tabs are condensed only in the displayed preview. Copy preserves the complete original content.
- Native submenus and keyboard behavior are preserved, and the menu remains available after closing the main window.

Requires **macOS 26.2 or later**. Supports Apple silicon and Intel Macs. The GitHub installer is signed with Developer ID and notarized by Apple.

Download `CoPaRe-v1.5.1.dmg` for manual installation. The matching `.dmg.sha256` file contains its checksum; `CoPaRe-v1.5.1.zip` is the signed in-app update archive.
