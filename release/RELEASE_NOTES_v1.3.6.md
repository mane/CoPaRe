# CoPaRe 1.3.6

CoPaRe 1.3.6 is a stability hotfix for Sparkle updates plus a small usability pass for the menu bar app.

## Highlights

- Fixed the Sparkle release signing workflow for sandboxed builds so future in-app updates can complete correctly.
- `Open CoPaRe` from the menu bar now reopens the existing main window instead of creating duplicates.
- Added visible version/build information in both Settings and the menu bar panel.

## Upgrade notes

- If you are currently on 1.3.2, 1.3.4, or 1.3.5 and in-app updating fails, install 1.3.6 manually once from GitHub Releases.
- After installing 1.3.6 manually, subsequent Sparkle updates should work normally again.
